# @opina/widget

Embeddable Opina CSAT / feedback widget (IIFE).

## CDN

```html
<script
  src="https://cdn.jsdelivr.net/npm/@opina/widget@1/dist/widget.js"
  data-key="pk_your_project_key"
  defer
></script>
```

Or point `src` at your self-hosted Opina instance: `https://your-opina.example/widget.js`.

## npm

```bash
npm i @opina/widget
```

Built files are in `dist/widget.js` and `dist/capture.js`.
